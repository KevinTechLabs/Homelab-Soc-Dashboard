Send pfSense's log to Sentinel
  1. In pfSense, open Status → System Logs → Settings.
  2. Under Remote Logging Options, tick Enable Remote Logging. Set Source Address to LAN and IP Protocol to IPv4.
  3. In Remote log servers, enter:
    …
  4. Under Remote Syslog Contents, tick Firewall Events and DHCP service events, then Save.

Block for your whole network
Connect Sentinel to pfSense (router blocking and devices in every zone)
  1. In pfSense, open System → Advanced → Admin Access. Under Secure Shell, tick Enable Secure Shell and set SSHd Key Only to Public Key Only. Save.
  2. Open System → User Manager, edit admin, and paste this into Authorized SSH Keys. Save.
    Tap “Make key” to create one
  3. Check the router address, then tap Connect.

Blocks go through pfSense's own easyrule command, so you can see and remove them under Firewall → Rules → WAN. This gives this server a key to your router's firewall; if it were ever hacked, the router could be changed too. Leave it off if that's a concern. The log view above works either way.

Wazuh SIEM

!
Alerts from Wazuh
!
Agent status
Connect Sentinel to Wazuh (read-only)
  1. In Wazuh, open Indexer management → Security → Internal users and create a user named sentinel. Then open Roles → readall → Mapped users and map sentinel.
  2. Open Server management → Security → Users, create sentinel-api, and give it the readonly role.
  3. On this server, run the setup and type the two passwords when asked:
    sudo python3 /opt/sentinel/sentinel_agent.py --wazuh-setup

Both accounts are read-only, so Sentinel can see Wazuh but can't change it. The passwords stay in a root-only file on the server and never reach this page. Each connection is pinned to the certificate Wazuh showed during setup.

Discord notifications

Connect a Discord channel
  1. In Discord, open your server's Server Settings → Integrations → Webhooks.
  2. Tap New Webhook, pick the channel for alerts, then Copy Webhook URL.
  3. Paste it here and tap Connect.
